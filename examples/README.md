# Examples

| File | What it is |
| :-- | :-- |
| [template.json](template.json) | Every field once, with placeholder content. Copy it to start a map |
| [dinosaur-extinction.json](dinosaur-extinction.json) | A worked example: what ended the dinosaurs |

The dinosaur map is here to show the format, not to settle the science. Its grades are a reasonable reading of the literature, not a verdict. It was picked because one well-known question happens to need every part of the protocol:

- **A deduction that is still uncertain.** Impact → years of darkness is valid logic, but rests on how much soot and sulfur reached the sky. So it is drawn thick (large if true) and faint (suggestive).
- **Abduction.** The pattern of who survived is best explained by a collapse of food webs.
- **Induction.** "Huge eruptions weaken ecosystems" is generalised from other mass extinctions, with counter-cases.
- **Big if true, not established.** Volcanic stress before the impact: large strength, contested confidence.
- **Multiply, not add.** If that stress was real, it amplified the impact rather than causing a second extinction.
- **Folklore.** "Mammals ate the eggs", kept in the map so it can be shown up.
- **Falsifiers** on every claim that carries weight.

To see it drawn, serve the repo folder and open the viewer (see [viewer/](../viewer/)).
